# گزارش آزمون‌های پذیرش

اجرا: `cd server && ../.venv/bin/python -m pytest tests/ -v` — آخرین اجرای واقعی: **۲۲ موفق، ۰ ناموفق**
(۱۵ پذیرش در `tests/test_acceptance.py` + ۷ سخت‌گیری در `tests/test_hardening.py`).

## یافته‌های بازبینی منتقدانه (دور دوم) و اصلاح آن‌ها

| ایراد یافت‌شده | شدت | اصلاح |
|---|---|---|
| `POST /api/admin/seed` بدون احراز هویت بود | بالا | فقط مدیر سامانه + آزمون خودکار |
| پاسخ دوباره به یک سؤال در آزمون، نمره را از ۱۰۰ رد می‌کرد | بالا | پاسخ جایگزین قبلی می‌شود + آزمون سقف نمره |
| پاسخ به سؤال خارج از آزمون پذیرفته می‌شد | متوسط | اعتبارسنجی عضویت سؤال در آزمون (۴۰۰) |
| تمرین هدایت‌شده وب بازخورد درستی نمی‌داد | متوسط | نقطه پایانی `/api/practice/answer` با بازخورد و ثبت اشتباه |
| ضبط صدا رضایت والد را بررسی نمی‌کرد | بالا | دکمه ضبط بدون رضایت والد غیرفعال است |
| زمان مطالعه همیشه صفر بود (وب هرگز ثبت نمی‌کرد) | متوسط | ثبت دوره‌ای زمان فعالیتِ قابل مشاهده |
| نقش مدیر به پنل والد می‌رفت و بازبینی محتوا نبود | متوسط | پنل مدیر: فهرست در انتظار تأیید + تأیید/انتشار + سید |
| آزمون آفلاین وجود نداشت (فقط تمرین موضوعی) | متوسط | بسته آفلاین شامل تعریف آزمون‌ها + اجرای آفلاین و صف همگام‌سازی |
| کانتینر وب nginx پروکسی `/api` نداشت | بالا برای استقرار | `web/nginx.conf` با پروکسی به سرور |
| تغییر گذرواژه وجود نداشت | کم | `POST /api/auth/change-password` + فرم در پنل والد |
| فایل اجرایی واحد وجود نداشت | — | `release/morabi-hoshmand` (۲۱MB)؛ آزمون از HOME خالی + ماندگاری پس از ری‌استارت |

اجرا‌نشده باقی‌مانده: APK (نبود زنجیره ابزار اندروید و مسدودبودن مخزن دانلود آن)،
آزمون روی گوشی واقعی، اجرای Docker در همین محیط.

آزمون بار/نفوذ حرفه‌ای، داوری متخصص محتوای درسی.
